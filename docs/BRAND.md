## 로고 최종 프롬프트

Use case: logo-brand. Create a finished original logo for Took Mac, a small native macOS personal planning app. Asset type: square app icon and GitHub README brand mark. Existing product palette is coral #F7826E, soft white, translucent glass; understated Korean productivity app, warm but precise. Design one exceptionally clean memorable emblem: a white rounded check stroke that also reads as a subtle lowercase t, inside a softly rounded coral glass square, with one very fine translucent concentric ripple hinting at a double tap. The silhouette must read clearly at 32 pixels. Polished restrained macOS icon craft, subtle dimensional glass bevel, controlled soft highlights, mostly flat front view, centered with generous transparent margins. No words, no letters beyond the abstract shape, no tagline, no watermark, no device mockup, no multiple concepts, no background surface, no cast shadow outside the icon. Output a single high resolution 1024x1024 PNG with a truly transparent alpha background around the icon. Original design, do not reproduce any existing Took logo.
